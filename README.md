RIFT — AI Assistant

RIFT is a futuristic AI assistant developed by Aryan Singh Rajput.

Features

- AI chat powered by Groq
- Voice input and spoken replies
- Neon blue and cyan interface
- Natural-language image generation requests
- RIFT branding and creator identity

Requirements

- Python
- Flask
- Groq API key

Deployment

This project is designed to run on Render.

Set "GROQ_API_KEY" in Render's environment variables.

Security: Never upload API keys, passwords, or private conversation data to a public repository.
